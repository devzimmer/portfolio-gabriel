01 — Problem

In Brazil, a SketchUp Pro subscription costs around R$ 2,400 a year, and a photoreal render takes expensive software and hours of light and material setup. Students and small studios are left out.

Lumuviz is a product line for them: a 3D modeler sold once, in the workflow they already know, and an AI service that turns a view of the model into a render, controlled in an architect’s vocabulary.

02 — What I built

Lumuviz 3D

A geometry engine from scratch

A boundary-representation model with auto-merging faces, push/pull, inferences and solid booleans, in plain TypeScript with no dependencies. Around 40 tools, including walls, openings and stairs.

Lumuviz 3D

.skp in and out, without SketchUp

Opens and saves SketchUp files, keeping texture coordinates. Ships as a browser app and a Windows app with offline licensing and per-customer updates.

Lumuviz

Render and edit by marking up

A screenshot becomes a photoreal render in 40–85 seconds. Users mark points and describe a change; edits chain into a version tree. Credits run on Stripe and a ledger in Postgres.

04 — Key decisions

  1. A

    Replace the proprietary SDK with an open library

    The official SDK’s terms block reselling. I rebuilt the file bridge on OpenSKP (MIT) behind the same interface and validated it on a real model: 1,029 groups and 12,267 faces, counts identical to the SDK’s.

  2. B

    Pick the image model by measured A/B

    Same screenshot, prompt and size across candidates, comparing tokens, cost and time. I chose the variant that best preserved materials and colour from the input, not the cheapest one.

  3. C

    Chain edits instead of patching pixels

    Pixel recomposition kept untouched areas exact but left ghosts and seams. Chaining each edit on the previous model response cut drift over three edits from 25% to 10% of pixels away from the marks. The trade-off: preservation is no longer exact.

05 — Measured, not guessed

−58–73%

cost per render, in benchmark

Every change to the renderer ships with its numbers.

The model switch also cut render time by 21–55%. When edits came back blurred, I measured sharpness, moved downscaling in-house with Lanczos and added a tuned unsharp mask, recovering about 98% of the original. Two bugs only showed up by looking at the image, not the metric.

06 — How AI built it

Spec, plan, then execution by subagents. The spec marks each decision as mine or the agent’s, and each plan names the edge cases its reviewer must check.

Parallel sessions in separate worktrees, and an overnight autonomous run that reported what was done, what was tested, what was not, and what needed my call.

A database security advisor caught a function that let anyone mint credits without logging in. It was closed in a migration before launch.
