01 — Problem

Small companies sell on WhatsApp, but the phone app cannot handle several agents, campaigns, a sales funnel or metrics. The official API can, if you run an approved Meta app, a token per client, webhooks and sending limits.

Duzi CRM runs one Meta app approved as a Tech Provider. Each company connects its own business account and number through Embedded Signup, and keeps using WhatsApp Business on the phone at the same time.

02 — What I built

Self-serve onboarding

Embedded Signup with coexistence: a company connects its number in a few clicks, and its token lands in the Vault, one per connection.

The CRM around it

Shared inbox, contacts and lists, sales pipelines, WhatsApp and email campaigns, profit by UTM, forms and “when → if → do” automations.

Gab, a read-only AI assistant

It answers with the asking user’s own permissions, cites its sources, filters links against prompt-injection exfiltration and is scored on a 30-case eval.

04 — Key decisions

  1. A

    A dedicated database role for secrets

    A security review found that Supabase’s service role can read the whole Vault and cannot be revoked. I created a login role with no tables, queues or Vault access that can only execute server functions, enforced by a CI check on the database catalog.

  2. B

    Store and enqueue before answering Meta

    Each webhook event is written and queued in the same transaction before the 200 goes back. Nothing lives only in memory; if the database fails, Meta retries. The cost is a slower response.

  3. C

    Start clean instead of growing a fork

    The first version was a hardened open-source fork for a single client. Going multi-tenant, its token and tenant model no longer fit, so I restarted and ported the proven parts one module at a time. Every migration since has a rollback, tested up, down and up again in CI.

05 — Proof, not promises

~2,300

pgTAP assertions on the database

Tenant isolation is tested, not assumed.

A cross-tenant matrix fails the build when a new table with an organisation id is not registered. A catalog check blocks tables without row-level security and policies that always pass. Around 945 Deno tests cover the edge functions, and a concurrency job runs two workers against the sending-limit ledger on every pull request.
